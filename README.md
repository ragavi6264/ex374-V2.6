```
student@workstation$ cd ex374-V2.6
student@workstation$ chmod +x git-v2.6.sh
student@workstation$ sh git-v2.6.sh
```

#### Instruction for V2.5

##### GitLab API (/api/v4/projects) with a Personal Access Token. GitLab won't accept your password for API calls.
###### Step 1: Create a token

In GitLab, open your avatar, then Edit profile, then Access Tokens. Create one with the api scope and copy it.

###### Step 2: Use this script
```
student@workstation$ cd ex374-V2.5
student@workstation$ chmod +x git-v2.5.sh
student@workstation$ sh git-v2.6.sh
< while running it will prompt for the token, paste it here >
```
